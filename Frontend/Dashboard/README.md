# Amrut Jewels Dashboard (Admin)

This is the admin dashboard for AmrutJewels (React + Vite).

## 📚 Documentation
- **[FUNCTION_LIST.md](./FUNCTION_LIST.md)** — full reference of admin API calls, socket/notification services, pages, components, hooks, and utils.
- **[REAL_TIME_NOTIFICATIONS.md](./REAL_TIME_NOTIFICATIONS.md)** — real-time notification architecture.

## Setup

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
